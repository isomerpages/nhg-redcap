<h4><strong>What this is about</strong></h4>
<ul data-tight="true" class="tight">
<li>
<p>The NHG-REDCap New Project Request Form has been updated to <strong>Version 6.2</strong>  <strong>(dated 14 Jul 2026).</strong>
</p>
</li>
</ul>
<h4><strong>What has been updated</strong></h4>
<ul data-tight="true" class="tight">
<li>
<p>Addition of new Section - <strong>Regulatory Classification</strong> - in
the Project Request Form, and the corresponding guidance information in
the accompanying Information Sheet.</p>
</li>
<li>
<p>Please <strong><em>read the Information Sheet carefully first</em></strong> before
completing the Project Request Form, as incomplete or incorrect submissions
will result in processing delays.</p>
</li>
</ul>
<h4><strong>Where to download</strong></h4>
<ul data-tight="true" class="tight">
<li>
<p>Download here: <strong><a href="https://redcapsupport.gri.nhg.com.sg/project-request-form/" rel="noopener nofollow" target="_blank">NHG-REDCap New Project Request Info page</a></strong>
</p>
</li>
<li>
<p>Please ensure you download a <strong>fresh copy </strong>of the Project
Request Form each time before completing it, as submissions using <strong>outdated</strong> versions
will not be accepted and returned for <strong>resubmission</strong>.</p>
</li>
</ul>

which contains:</p>
<ul data-tight="true" class="tight">
<li>
<p>REDCap New Project Request Form (.docx)</p>
</li>
<li>
<p>Information Sheet for New Project Request submission (.pdf)</p>
</li>
</ul>
</li>
</ul>
